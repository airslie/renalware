# Letters Module

Letters are one of the most powerful components of Renalware as they create an extensive record of the patient’s history with details of the patient’s Problem List, Medications, Observations and Pathology results at the time of the letter creation.

Three separate letter types can be created from a patient's Letters page:

- Clinic Visit Letter
- Clinical Letter
- Simple Letter

Many Renalware letters are Clinic Visit Letters which are created from a specific patient clinic encounter (via the Clinic Visits listing). A Clinical Letter will generate a letter not linked to a particular clinic visit. Simple Letters do not display Problem List, Medications or Pathology Results, and are often used for correspondence with non-medical colleagues or other recipients.
