# Patient Functions

Apart from the specialist nephrology data collected and displayed for Renalware patients and the various modalities (HD, PD, Transplant, etc) there are various "generic" features which are applicable to all patients. These include Problem and Prescription lists, Events, Clinical Visits, and other information. (Letters are also a core feature of Renalware and that module is discussed in a separate section.)
