# Activity Summary

Below the current Problem list and Prescriptions section on the Clinical Summary screen is a display of the six most recent Activity Summary episodes. These include any Admissions, Clinic Visits, Letters, Events, Consults and Messages and are presented with the most recent at the top.

:::note

Note: additional patient events may be added to the Activity Summary list in the future. (This feature was previously called "Timeline".)

:::

![Timeline portal on Clinical Summary screen](/img/user-guide/clin_summ_timeline.png)

*The Clinical Summary with the Timeline portal displaying recent key patient events*

This functionality exists to allow Users quickly to see any new things which have happened to the patient. The text associated with each episode can be toggled by clicking on the Down Arrow to the left of the Episode. Multiple episodes can be toggled or all of them displayed by clicking on the double Down Arrows at the top. A full set of Timeline episodes can be accessed by clicking on the Timeline link (blue) or the Timeline link in the Left Gutter.
