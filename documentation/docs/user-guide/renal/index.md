# Renal Module

The renal module comprises a number of specialty screens and functions relating to general nephrology, renal diagnose(s) and End Stage Renal Failure information, as well as haemodialysis (HD), peritoneal dialysis (PD), transplant, and access data for relevant patient populations. 

Note that some Renalware users (e.g. HD or PD clinicians and nurses) will use a given component on a regular or even daily basis whilst others may never use it at all. Similarly, only patients with a relevant modality history will have various navigation links in the left gutter.

:::note

Remember that all of Renalware and the Renal Module functions in particular are in constant development so you may encounter new features not yet included in this User Guide.

:::
