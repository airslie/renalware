# Access Summary

Information about patients’ access for dialysis are recorded and displayed through the Access Summary screen (left gutter). This covers Access Procedures (so both for HD and PD), Access Profile, Access Plan, Access Assessments, Ease of Needling of Vascular Access (MAGIC) and Risk of Venous Needle Dislodgement (VND). Data can be entered via the `Add` button at the top or by `Edit / Add` in each section.

Many of these fields are also displayed on relevant other screens elsewhere. For example Access Profile, Access Plan, MAGIC and Risk VND are shown on HD screens.
