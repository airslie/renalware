# User Registration

## Account Creation

:::note

In some hospitals the local LDAP system may be used for login and authentication. See below and consult with your local IT support team if you have any questions about this.

:::

If you have not used Renalware previously and are not registered as a User, you need to *create an account*. Click on the `Sign Up` link on the login screen. All fields need to be completed and it is probably best to make your user name the same as your Windows login. Your email address should be your work email (NHS.NET) and this is required for Password reset if you forget your password.

Once you have completed the fields, Save and your account will be created. An Administration user will then be able to activate your account and set your level of access (e.g. Read Only, Clinical, Prescriber etc).

## LDAP Accounts

If your trust uses LDAP, you will sign into Renalware using your Trust Windows username and password which Renalware will confirm is correct using LDAP. If you have forgotten your password, you will need to reset this using the Trust procedures for resetting your Windows password -- the Renalware password reset therefore is not relevant. Similarly you will not need to Sign Up to Renalware when you first start using the application although the Renal Admin team will help set your level of access to the application.

## Onboarding Process

:::info New

Onboarding was added to Renalware in July 2025. Earlier users will not be familiar with it.

:::

At some Renalware sites, new users will be asked to complete an online *Onboarding* process. This consists of a series of short video lessons (typically 2-3 minutes long). Ideally these are completed in a single session, but one can quit at any time and resume later.

At the end of the course there is a simple registration form to fill out. Once this has been received by the hospital IT administrator(s), your account will be activated.

## Update Profile

Once you can access your account, you can update your Profile at any time. You access this via your Username at the top of any screen and scroll down to `Update Profile`.

## Forgotten Password

If you forget your password, you can click on the `Forgotten Your Password?` link on the Login screen and you will be sent an email enabling password reset for your account.

## Password Resets

Per National Cyber-Security Centre guidelines, Renalware does not enforce regular password resets. At each login and on the User dashboard it displays the date and time of the last Log In by the user.
