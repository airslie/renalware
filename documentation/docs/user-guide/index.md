# Renalware User Guide

This site documents the the most important features of the current version of Renalware.

:::important

Not all features documented here are available in all Renalware hospital sites. In addition, depending on your user level you may not have access to some screens or functions.

Also please note that the Renalware application is under constant development and that the current live version may contain features not included yet in this guide and screen elements may look different from the screenshots displayed herein.

:::

### Navigation

Use the sidebar to browse the User Guide. On smaller screens, open the navigation menu. Longer pages also have a table of contents.

### Searching the User Guide

Use the search box at the top of the screen to search both the User Guide and the Administration & Technical documentation.

### "Onboarding" Videos

A series of &ldquo;Onboarding&rdquo; training videos [is also available](https://airslie.com/rw_onboarding/). These are designed principally for new users but may be viewed or re-viewed at any time. (From July 2025 most new Renalware users will have watched these prior to using the application.)

#### Onboarding Video Topics

- Dashboard Letters
- Bookmarks
- Messages
- Electronic CCs
- Finding a Patient
- Clinical Summary
- Problems
- Prescriptions
- Events
- Clinic Visits
- Letters
- Main Nav Bar
- User Guide
