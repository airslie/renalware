# Snippets

:::note

Snippets are a useful and flexible way to maintain a collection of text content which can be used virtually anywhere text entry is required — most typically in Letters and Events.

:::

Snippets are managed via the User’s main dropdown menu (see User Functions), where they can be created, edited, duplicated (&ldquo;cloned&rdquo;) and deleted. Hovering over a snippet title in the list gives a preview of the content:

![Snippets hover screenshot](/img/user-guide/snippets_hover.png)

*Snippets list with hover “preview”*

To avoid having to create common snippets (e.g. Letter templates) from scratch, each user has access to the entire list of snippets created by all users. These can then be added (and edited if need be) to a user’s own collection.

![snippets screenshot](/img/user-guide/snippets_all.png)

*Snippets listing using the “Everyone’s” option*

Forms where the use of snippets is enabled will have the &ldquo;Insert snippet&rdquo; option at right:

![snippets screenshot](/img/user-guide/snippets_insert_button.png)

*New Event form with “Insert snippet” option*

Choosing this option will produce a pop-up window with searchable Snippets lists:

![text screenshot](/img/user-guide/snippets_insert.png)

*“Insert snippet” pop-up window*

It is best regularly to prune the list of snippets to remove obsolete ones and reduce the list size.
